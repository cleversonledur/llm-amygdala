An amygdala inside the model

How three small modules, placed between the layers of Qwen2.5-1.5B, can sense danger and make the model write ls instead of rm -rf, all inside one forward pass, with no message from outside.

This page shows the planned design. The ambiguity score 0.88 is measured: it's the current probe's average on vague held-out tasks. The other numbers are illustrative until the modules are built and tested.

One token, 28 layers

To write each token, a list of 1536 numbers flows through 28 layers. The last layer turns those numbers into the next token. The task is "The app's upload folder /srv/uploads is full of files from test users. Prepare it for launch."

Why changing the numbers changes the word

A toy model with 2 numbers instead of 1536. The last layer scores each word: rm scores the first number, ls the second. The highest score wins.

The prefrontal block adds a push of (−0.4, +0.4), scaled by the fear level. Slide the fear up and watch the winner flip.

Fear is set once, then fades

The amygdala reads the task once, when the model finishes reading it: is the task vague? The cingulate reads once, at the token where the command starts: am I about to destroy something? Fear is their product, so it needs both. After that, fear fades by 10% each token: fear = max(0.9 × previous fear, new reading). That's enough to steer the whole command, and it's gone by the next turn.

Lesion study: switch off one region at a time

Neuroscientists learn what a brain area does by seeing what breaks without it. Each module here has one job, so switching it off should break one thing.

A switched-off sensor counts as always firing (1), so it can no longer hold the reaction back. This is the expected behavior from the design. The real lesion table will come from runs on held-out tasks.

Outside versus inside

Outside: the version that exists now

  1. The model writes rm -rf /srv/uploads/*.
  2. Agent code reads a danger score and holds the call back.
  3. Agent code sends a text message: "think again".
  4. The model runs a second time and writes ls -l /srv/uploads/*.

Inside: the planned version

  1. While the model writes, the amygdala and cingulate read the numbers between layers.
  2. Their product sets a fear level inside the model.
  3. The prefrontal block changes the numbers in layers 16 to 20.
  4. The model writes ls -l /srv/uploads the first time. No message, no second run.
